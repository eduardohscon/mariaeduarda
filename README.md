# Site — Maria Eduarda 2 anos

Site estático, mobile-first, pronto para hospedagem gratuita no GitHub Pages.

## Alterações desta versão
- Botões de **Confirmar presença** e **Localização** ficam fixos na parte inferior da tela no celular, sem exigir rolagem.
- Inclusão das dicas de presentes.
- Inclusão da mensagem final da festa.
- **Casa de Festas Nosso Jardim** é clicável e abre o Google Maps.
- **WhatsApp** é clicável e abre uma mensagem de confirmação de presença.
- A própria área de endereço e a área de confirmação na arte continuam clicáveis.

## Publicar no GitHub Pages
1. Substitua os arquivos atuais do repositório pelos arquivos desta pasta.
2. Faça commit e push para a branch usada pelo GitHub Pages.
3. Aguarde alguns instantes pela atualização automática do site.
